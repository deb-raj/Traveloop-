TravelLoop

A modern full-stack travel booking web application built with React, Vite, Tailwind CSS, and Spring Boot.

🚀 Features
User Authentication
Browse Travel Packages
Search & Filter Destinations
Booking System
Responsive UI
Secure Backend APIs
Modern React Frontend
REST API Integration

⚙️ Frontend Setup
Clone Repository
git clone <your-repository-url>
Navigate to Frontend
cd traveloop-frontend
Install Dependencies
npm install
Start Development Server
npm run dev

Frontend runs on:

http://localhost:3000
⚙️ Backend Setup
Navigate to Backend
cd traveloop-backend
Run Spring Boot Application

Using IntelliJ IDEA or:

./mvnw spring-boot:run

Backend runs on:

http://localhost:8080
🔗 API Integration

Frontend communicates with backend using REST APIs.

Example:

GET /api/packages
POST /api/bookings
